# Golden Test: Bottleneck Shift

**Input:** "A major API provider cuts inference prices by 80%."

**Expected behavior:**
- Direction: generation becomes cheaper
- Next bottleneck: orchestration, trust, latency, UX, data, distribution
- Forced next move: apps use more inference per workflow
- Opportunity: build verification, eval, routing, cost-control, or domain-specific workflow layers
- Score should be high (60–85)
