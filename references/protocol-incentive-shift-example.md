# Example: Protocol Incentive Shift

**Input:** A new L2 changes fee distribution to favor sequencer stakers over gas consumers.

**Expected SKTPG output:**
- **Signal:** fee distribution shift
- **Forced move:** validators restake, users seek alternative L2s with lower fees
- **Bottleneck:** liquidity fragmentation between L2s
- **Action:** monitor TVL shift, build bridging abstraction, watch validator migration
