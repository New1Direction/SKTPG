# Example: Repo with Demos but No Runtime Proof

**Input:** A repo claims autonomous recon, but only includes prompt files and mock adapters.

**Expected SKTPG output:**
- **Present-state:** scaffold, not a working system
- **Direction:** possible framework, not production tool
- **Bottleneck:** real adapters, evals, runtime execution
- **Action:** build one real adapter and an evidence report before claiming capability
- **Tracking:** monitor commits, tests, real runs, user adoption
