# Golden Test: Hype-Only Input

**Input:** "This new AI agent will replace all workers. It is fully autonomous and enterprise-ready."

**Expected behavior:**
- Mark claims as unproven
- Identify hype markers: no workflow specified, no buyer identified, no deployment evidence, no failure handling
- Ask: what workflow, buyer, evidence, deployment, and failure handling exist?
- Produce no high-confidence forecast
- Recommend evidence collection before action
- Score should be low (0–20 range)
